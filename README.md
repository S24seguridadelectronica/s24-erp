# S24 Platform - Sistema Integral de Gestión

Sistema ERP + CRM + CMS + Call Center para S24 Seguridad Electrónica.

## Tecnologías
- React 18 + TypeScript + Vite
- React-Bootstrap + Lucide Icons
- Supabase (PostgreSQL + Auth + Storage)
- React Hook Form + Zod

## Instalación
```bash
npm install
npm run dev
```

## Configuración
1. Copia `.env.example` a `.env`
2. Configura tus credenciales de Supabase
3. Ejecuta la migración SQL en el SQL Editor de Supabase

## Módulos
- Dashboard, CRM, Call Center, Ventas, Operaciones, Inventario, Finanzas, CMS, Administración.
